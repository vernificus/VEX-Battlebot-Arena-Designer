# Battlebot Field Planner

A React-based interactive application for teachers to plan out a battlebot field using VEX IQ field pieces. This tool provides a drag-and-drop interface for placing hazards and configuring the floor layout.

## Features

- **Interactive Grid**: Edit the floor layout or place hazards.
- **Two Modes**:
  - **Hazard Placement**: Drag and drop specific balloon challenges.
  - **Floor Layout Editor**: Toggle tiles to create custom field shapes.
- **Print Support**: Optimized print layout for classroom use.
- **Challenge Palette**:
  - Zig-Zag
  - Tight Corner
  - The Cave
  - 12in Tower
  - Moving Spinner
  - Jail Cell
  - Dead End
  - Suspended Trap
  - Stacked Duo
  - 6in Step

## Development

This project uses [Vite](https://vitejs.dev/) + [React](https://react.dev/) + [Tailwind CSS](https://tailwindcss.com/).

### Install Dependencies
```bash
npm install
```

### Run Dev Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

## Deployment

The project is configured to deploy to GitHub Pages automatically via GitHub Actions.
